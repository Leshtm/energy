# Сборки

Здесь лежат собранные APK и файлы `version-<сборка>.json` рядом с ними —
описание этой сборки: номер, смысловая версия, ссылка на ассет релиза и
хеш файла.

Воркфлоу «Публикация сборки в релиз» берёт отсюда APK и его `version.json`,
сверяет хеш и делает из них GitHub-релиз. Никакой внешний хостинг для этого
не нужен: всё лежит в этом же репозитории.

| файл | что это |
|---|---|
| `energy-<сборка>.apk` | собранный и подписанный APK |
| `version-<сборка>.json` | ответ сервера обновлений для этой сборки |
