# Сборки

Здесь лежат собранные APK: файл `energy-<сборка>.apk` — это подписанная
сборка, готовая к установке.

Воркфлоу «Публикация сборки в релиз» делает из каждой такой сборки
GitHub-релиз: приложение спрашивает у GitHub API последний релиз и берёт оттуда
файл, ссылку на него и хеш. Никакого отдельного файла с описанием сборки
не нужно — GitHub отдаёт всё, что нужно, одним ответом.

## Как выпустить сборку

1. Положить APK в эту папку под именем `energy-<сборка>.apk` и закоммитить
   его в репозиторий. Имя версионное: сборка `0.8.7.56` — это файл
   `energy-0.8.7.56.apk`, а номер после последней точки — он же номер
   сборки, который приложение сравнивает со своим.
2. Открыть Actions → «Публикация сборки в релиз» → Run workflow, вписать
   номер сборки и одной строкой — что изменилось. Эта строка станет
   описанием релиза и появится в диалоге обновления на магнитоле.

Всё. Никакого сервера и никакой раздачи по FTP: файлы лежат здесь, релиз
создаёт GitHub.
